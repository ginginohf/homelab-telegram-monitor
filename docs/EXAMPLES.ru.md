# Пример работы

[English](EXAMPLES.md) | [О проекте](../README.ru.md)

Вывод настоящих функций форматирования с тестовыми состояниями служб и GPU. Аккаунт Telegram и отправка сообщений не используются.

Из корня проекта, после установки зависимостей:

```sh
python3 examples/demo.py
```

Фактический вывод:

```text
Сервер: есть замечания
✅ web-demo
⚠️ backup-demo

Замечания: backup-demo
Проверено: <current UTC time>

Видеоядро Intel: 96.2% (самый занятый блок, среднее за 10 с)
GPU: копирование 0.4%, 3D/вычисления 8.1%, видеокодеки 96.2%
```
